Texloom v0.2 implementation agreement

Historical implementation assignment. Use src/schema.ts and docs/ir-contract.md
for current semantics, docs/runtime-contract.md and docs/ROADMAP.md for new work.

Maintain v0.1 reading/playing/compilation. New frontend opt-in package texloom-tikz.
Core Bundle.version accepts '0.1'|'0.2'. Version 0.2 adds anchor-aware geometry.

GroupNode: optional anchors: Record<string,[number,number]> in local space.
Compiler lowers each named TikZ node to a group with author ID; its vector art
is a child tex node. Group transform.translate is node position in scene bp.
Actual PGF-computed shape anchors are recorded relative to the node center,
with y flipped to our +down convention. Artifact child offsets compensate the
real TeX resource baseline/center, preserving shape and text appearance.

New relations (prefer resolve through all parent/local affine transforms):
 {type:'connect',target,from:{node,anchor},to:{node,anchor},bend?:number}
 target is existing path node; evaluate writes d. bend is signed perpendicular
 distance in target-parent space, in bp; zero -> line, nonzero -> cubic curve.
 {type:'pathLabel',target,path,position:number,offset:number,rotate?:boolean}
 target is tex node; writes x,y (baseline), optionally transform.rotate.
 position 0..1 is Bezier parameter (not claimed arc length), offset signed bp.
 center the label using its metrics (x adjusted by width/2; y by height/depth).

PathNode optional arrowEnd:boolean, arrowStart:boolean, arrowSize:number.
Evaluator supplies resolvedPath?:{start:[x,y],c1:[x,y],c2:[x,y],end:[x,y]}
when generated by connect. Renderer uses it for end/start tangent oriented
triangle arrowheads (own simple initial implementation, not claimed PGF Stealth).
Coordinates and d live in target's own local space. Participants in different
parent groups may connect; all transforms considered. Reject singular inverse
transforms with diagnostics. A target's transform is inverted when needed.
Labels resolve path geometry into label-parent space and use real TeX metrics.
Semantics for rotated labels must be explicit; implement false by default.
Do not allow same property multiple writers, nor hierarchy/dependency cycles.
Existing v0.1 relation identity/local-space restrictions may remain.

Frontend target syntax, exact supported options may be refined by compiler agent:
 \begin{loomscene}[width=960,height=540,duration=12,title={...}]
 \loomnode[draw=...,fill=...,rectangle,minimum width=..., ...]
   (A) at (240,240) {$X$};
 \loomconnect[draw=...,->,bend=0] (f) (A.east) to (B.west);
 \loomlabel[at=.5,offset=-14] (f-label) on (f) {$f$};
 \loomanimate[duration=12,easing=smooth] (A) {move to={(340,320)}};
 \end{loomscene}
Reuse PGF keys and actual TikZ node/shape/style/path execution. Do not parse all
TikZ source with Python regex. Explicit supported wrappers capture intent.
Named styles via \loomset or normal \tikzset retained via generated setup.
Actual TikZ static path wrapper can compile full native paths to a resource.
Scope/groups should be explicit author IDs with transforms, nested support.
